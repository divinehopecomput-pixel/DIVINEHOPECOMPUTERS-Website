# Divine Hope Computers and Training Center

Responsive storefront website for computers, laptops, accessories and IT training.

## Features
- Responsive layout for desktop, tablet and mobile
- Product cards with real product photography
- Search, category filters and price/name sorting
- Shopping cart with quantity controls
- Cart saved in the browser using localStorage
- Contact form placeholder and demo checkout notice

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish and use the URL shown on that page.

## Before accepting real orders
This is a front-end demo, not a complete production ecommerce backend. Product prices are sample placeholders. The cart is stored in the customer's browser only; orders are not sent to a server, and checkout does not process payments. Before taking real orders, connect a secure backend/database, configure verified business contact details, and integrate a trusted payment provider. Never store payment-card details directly in this static page.
